# Fonts

This directory stores bundled font families, with each family in its own folder. Family folders contain the font files, upstream documentation, and the applicable licence.

## Included fonts

- **Roboto** (`Roboto/`): Variable and static TrueType fonts, including regular, condensed, semi-condensed, and italic variants. Licensed under the [SIL Open Font License 1.1](Roboto/OFL.txt). See [the upstream README](Roboto/README.txt) for font details.

## Adding fonts

Create a folder named after the font family and include its original licence and any required attribution alongside the font files. Keep these notices when copying or redistributing fonts, and check the family's licence before modifying or bundling it.

Font files retain their own licences; the repository's MIT licence does not replace them.

Protected by default

Your authentication cookies belong in an encrypted account store. RM uses Windows-held keys by default, with the code available for inspection.

Encryption before storage

Your account store is encrypted with AES-256-GCM before it reaches disk. Authentication cookies are not saved as plain text.

A key held by Windows

The default wrapping key lives in Windows Credential Manager. If you prefer a master password, the optional password mode derives its wrapping key using Argon2id.

Secret redaction in logs

Known cookie, authentication-ticket, and CSRF-token patterns are redacted before log output is written to disk.

Recovery from interrupted saves

Atomic writes and a backup of the previous store help protect saved data if a write is interrupted.

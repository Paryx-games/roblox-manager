# First session

Use Roblox Manager to prepare and launch Roblox sessions from one place.

### Before you begin

Have the following ready:

* A Windows device with Roblox Manager installed.
* The Roblox account you want to use.
* The game you want to launch.

{% hint style="info" %}
Start with one account. Add more accounts after your first successful launch.
{% endhint %}

### Start your first session

{% stepper %}
{% step %}
### Open Roblox Manager

Start Roblox Manager on your Windows device. The app is your central place for accounts and game sessions.

A new store uses device encryption and normally unlocks automatically on this Windows user. An existing password-mode store asks for its master password. A first-launch walkthrough can be followed or skipped. After an upgrade, acknowledge the changelog with **Continue**.
{% endstep %}

{% step %}
### Add an account

Add the Roblox account you want to use. Keep each account organized so you can select it later.

Open **Accounts > Add account > Log in with browser** and finish the Roblox login. Wait for the account to appear in the list. Closing the login window cancels the flow. Cookie entry and bulk import are alternatives in the same menu.
{% endstep %}

{% step %}
### Choose and launch a game

Select your account and the Roblox game you want to play. Launch the session from Roblox Manager.

Enter the game's numeric **Place ID** in the launch controls and choose **Launch**. Leave optional server and launch-data fields empty for a normal public game launch. Open **Instances** after the client starts to inspect or focus it.
{% endstep %}
{% endstepper %}
